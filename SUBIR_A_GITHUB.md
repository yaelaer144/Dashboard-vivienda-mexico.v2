# Subir esta versión a GitHub

La estructura del ZIP ya está preparada para GitHub Pages.

**Importante:** al descomprimir, sube los archivos que están dentro del ZIP directamente a la raíz del repositorio. `index.html` debe quedar en la raíz, no dentro de una carpeta llamada `dashboard_vivienda_GITHUB_READY_20260908`.

Después configura **Settings > Pages > Deploy from a branch > main > /(root)**.

Para actualizar datos manualmente desde GitHub, abre **Actions > Actualizar datos del dashboard > Run workflow**.
